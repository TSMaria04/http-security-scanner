# 🛡️ HTTP Security Header Scanner

Простой и эффективный CLI-инструмент на Python для автоматизированного анализа HTTP-заголовков безопасности веб-сайтов. Проект предназначен для первичного аудита защищенности веб-ресурсов и выявления уязвимостей конфигурации сервера

---

## 🚀 Функционал

- 🔍 **Автоматическая проверка критических заголовков:**
  - `Strict-Transport-Security` (HSTS)
  - `Content-Security-Policy` (CSP)
  - `X-Frame-Options`
  - `X-Content-Type-Options`
  - `Referrer-Policy`
  - `Permissions-Policy`
- 🎨 **Цветовая индикация результатов** в консоли для удобного чтения отчета
- 📊 **Расчет общего индекса защищенности** сайта в процентах
- ⚠️ **Оценка рисков:** краткое пояснение угроз при отсутствии каждого из заголовков

---

## 🛠 Технологический стек

* **Язык:** Python 3.12
* **Библиотеки:** 
  * `requests` — отправка HTTP/HTTPS запросов и получение заголовков ответа
  * `colorama` — форматирование и подсветка вывода в терминале

---

## 📥 Установка и запуск

1. **Копируйте репозиторий:**
   ```bash
   git clone [https://github.com/TSMaria04/http-security-scanner.git](https://github.com/TSMaria04/http-security-scanner.git)
   cd http-security-scanner

```

2. **Установите зависимости:**
```bash
pip install requests colorama

```


3. **Запустите сканер:**
```bash
python scanner.py

```
